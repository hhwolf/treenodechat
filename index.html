RECOMMENDATION MEMO

A layered evaluation strategy for production ML

Combine stable offline gates with live performance signals. No single score is sufficient once models encounter real users and shifting data.

Success criteriaReliabilityDetection < 24hCost-aware
01

Use a layered evaluation stack

Treat evaluation as a feedback system, not a launch gate. Each layer answers a different question and catches a different failure mode.

CONTRARIAN REVIEW v0.3
CRITICAL RESPONSE

The layered model may be too slow to operate

The proposal is sound in theory, but it assumes a level of evaluation maturity the current team does not yet have.

CORE CHALLENGE

Three evaluation layers create three ownership boundaries. Without a single accountable operator, failures will fall between teams.

01

Start with one operational loop

Ship a focused canary process first. Prove the team can detect, triage, and resolve regressions before expanding the system.

NowCanary + 5 critical slicesOne owner · two weeks
ThenAdd only proven signalsExpand from incidents
02

Challenge the 24-hour target

Fast detection is only useful if the team can act. The memo needs an explicit response owner and escalation path.
